## 운영 방식

스터디캠프에는 정해진 기수가 없습니다. **리더가 다루고 싶은 주제로 언제든 스터디를 열고, 모집하고, 진행합니다.**

GitHub 저장소를 쓰는 스터디는 이렇게 운영됩니다:

1. 리더가 과제·정리 **템플릿 저장소**를 만듭니다
2. 참여자는 Classroom에서 **Accept** 한 번으로 자기 전용 정리 저장소를 받습니다
3. 각자 자기 저장소에 정리를 쌓고(push = 제출), 리더가 새 챕터를 올리면 `./sync.sh` 로 받아갑니다
