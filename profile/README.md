## 이 GitHub 조직의 용도

이곳은 스터디캠프의 **학습 기록 보관소**입니다.

- **템플릿 저장소** — 스터디마다 리더가 만드는 과제·정리 틀의 원본
- **참여자별 정리 저장소** — 참여자 한 사람당 하나씩 생성되는 개인 기록 공간
- **운영 저장소** — 블로그, 교실 관리 데이터 등

스터디가 끝나면 저장소는 아카이브되어 기록으로 보존됩니다. 모든 정리 저장소는 공개가 원칙이라, 참여자는 언제든 자신의 기록을 fork해 가져갈 수 있습니다.

## 스터디는 이렇게 관리됩니다

참여자 저장소 생성과 명단 관리는 [Classroom 50](https://classroom50.org)으로 자동화되어 있습니다.

```
리더: 템플릿 저장소 준비 → 운영진: 교실·과제 등록, 참여자 초대
                              ↓
참여자: 초대 수락 → Accept 클릭 → 내 전용 정리 저장소가 자동 생성
                              ↓
각자 정리 작성 후 push (= 제출) · 새 챕터는 ./sync.sh 로 받아가기
```

- 참여자는 저장소를 직접 만들거나 설정할 일이 없습니다 — **Accept 한 번**이면 시작됩니다
- 리더가 템플릿에 새 챕터를 올리면, 참여자는 자기 저장소에서 `./sync.sh` 한 줄로 받아갑니다
- 제출 현황은 Classroom 대시보드에서 한눈에 확인됩니다

## 스터디를 열고 싶다면

리더가 되는 데 자격 조건은 없습니다. 이것만 정해서 **운영진에게 신청**해주세요:

1. **주제와 진행 방식** — 무엇을, 어떤 호흡으로 (책 완주, 과제 풀이, 설계 연습 등)
2. **정리 틀** — 참여자가 무엇을 기록하면 좋을지 (운영진이 템플릿 제작을 도와드립니다)
3. **모집 규모와 기간**

운영진이 모집 공지, 템플릿 저장소, Classroom 세팅까지 함께 준비합니다. 리더는 콘텐츠에만 집중하면 됩니다.
